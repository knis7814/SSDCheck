# SSDCheck

## 本项目初始说明

本项目初始时，只为测试SSD性能，因本人手上有一块SSD存在性能问题，故开始详细了解SSD如何进行测试

项目的后续过程则逐渐变为作为个人系统学习SSD信息以及个人学习过程的记录

## 项目内容概述

项目将分为基础篇和实际脚本实操篇，基础篇将讲解基础SSD知识，实操篇为可以直接执行测试的基础命令，目前命令以Linux sh脚本为主，后续会统一更改为python脚本编写以方便多平台测试

如果你只想测试自己SSD的性能，可直接进入实操篇

# 基础篇

基础篇将分为以下几个内容：
1. SSD概述
2. 核心技术
3. 内部架构
4. 关键算法
5. 性能指标
6. 测试方法
7. 优化指南
8. 故障排除
9. 其他资源


# 实操篇
实操篇将分为以下几个内容：
1. 磁盘基础信息获取与设备预处理
2. SSD预处理
3. 性能测试篇
4. 可靠性与耐久性测试篇
5. 兼容性测试篇
6. 稳定性测试篇
7. 功能性测试篇
8. 用户场景测试篇
